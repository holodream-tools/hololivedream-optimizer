# hololive Dreams 隊伍最佳化

從你持有的卡片裡找出最強的五人隊伍，並計算指定歌曲的預估分數。

**▶ https://holodream-tools.github.io/hololivedream-optimizer/**

免安裝、免註冊。所有計算都在你的瀏覽器裡完成，卡片庫存只留在這台裝置，不會上傳。

<br>

## 怎麼用

**1 · 我的卡片** — 勾選持有的卡、設定命座、開啟 Leader Outfit。

> 批次按鈕只作用於「目前篩選出來的卡」，先篩選再批次最快。
> 右上可切換**清單／卡片／卡片＋技能**三種檢視。
> 設定完請按**匯出**存一份備份。

**2 · 隊伍最佳化** — 按下計算，把所有五人組合 × 所有 Leader Outfit 全部算過一遍。

> **指定必須上場的卡**：想用某張卡就先鎖定，剩下空位交給計算，鎖越多算越快。
> **顯示筆數**：5–30 之間隨時調，不用重算。
> 點**這個數字怎麼來的**可展開分數組成。

**3 · 歌曲／順序** — 選一支剛算好的隊伍，再選歌，得到 Perfect-FC 預估分與最佳站位。

> 五個 Special 的發動時間由譜面固定，誰站哪一格會改變覆蓋到的音符，所以 120 種排法會全部試過。

另有**卡片庫**（查各命座的能力值與技能）與**自選隊伍**（自己挑五張試算）。

<br>

## 注意事項

| | |
|---|---|
| **推薦指數不是遊戲分數** | 它是隊伍之間的**相對比較值**，回答「哪隊比較強」，不回答「能打幾分」。要看分數請用「歌曲／順序」。 |
| **未納入** | Board、Connect、Memory、Fever、玩家失誤。兩種模式都假設全 PERFECT。 |
| **庫存存在瀏覽器** | 換裝置、換瀏覽器、清除網站資料都會消失。**請匯出備份。** |
| **圖片是外部引用** | 本站不存放圖片檔。來源失效時圖片會消失，功能不受影響。 |
| **資料可能落後** | 卡片資料為社群整理，新卡可能延遲；譜面需等網站更新。 |
| **計算吃 CPU** | 完整搜尋可達數億次評估，筆電會發熱，可隨時取消。 |

## 分數是怎麼算的

### 推薦指數

```
① 基礎能力    五張卡在所選命座下的 Lv.80 三圍，加總
② Passive     依總能力高低依序套用，每個效果分開無條件進位
③ Outfit      條件符合才生效；「全員 Score Support」整隊只算一次
④ Special     Σ (score_support × 持續秒數 ÷ 192)
⑤ Active      覆蓋率 = min(1, 發動機率 × 持續秒數 ÷ 判定間隔)
⑥ 合成        推薦指數 = 總合力 × (1 + Active倍率)
              Active倍率 = Active期望 ÷ 100 × (1 + 各項Support ÷ 100)
```

三個容易被問到的地方：

**Active 重疊只取最強，不是相加。** 所以算的不是總和，而是「當下實際生效的那個」平均有多強：

```
效果由強到弱排序後
平均效果 = Σ  效果ₖ × 機率ₖ × Π(1 − 機率ⱼ)     j = 所有比它更強的效果
```

一個效果要成為「當下最強」，前提是比它強的都剛好沒發動。

**Score Support 本身不加分。** 它只在括號內，作用是放大**正在生效的** Active——Active 沒發動時，Score Support 再高也不產生分數。這是本工具與部分其他計算器數字有落差的主因。

**每個百分比效果分開進位**，不是加總後才算一次。

> ④ 的 192 秒是固定參考長度，不是實際歌長——這個模式本來就不知道你要打哪首歌。

### 指定歌曲

```
① PERFECT 基礎分 = floor(總合力 ÷ 該譜面分數除數)
② 逐音符加總      一般音符用基礎分，中間音符用其十分之一（進位），各乘音符權重
③ 當下加成        看該瞬間有哪些 Special／Active 生效，同樣「只取最強」
④ 站位            120 種排法全部算過，取最高分
```

分數除數取自 [Hololive Dreams Lab](https://dreams.wf-calc.net/simulator)。結果是「全 PERFECT 且 Life 全滿」前提下的估計值。

## 開發

```bash
npm install
npm run dev      # 開發伺服器
npm test         # 與 Python 參考實作的對照測試
npm run build
```

計算引擎移植自一份 Python 實作，兩邊由對照資料鎖住：推薦指數逐位元相同、切分後的 Top-N 與單執行緒版本一致、譜面分數在 78–2022 音符全範圍相符。測試沒過就不會建置。

`public/data/` 由本機的 Python 專案（未公開）匯出，腳本在 `tools/`。一般開發不需要這步。
